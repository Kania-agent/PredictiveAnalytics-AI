# PredictiveAnalytics-AI

**AI-Powered Forecasting & Trend Analysis Platform**

PredictiveAnalytics-AI is a data science-themed forecasting dashboard built with MiMo V2.5 intelligence. It provides CSS-based trend visualization, prediction cards with confidence intervals, and accuracy metrics for data-driven decision making.

## Features

- **Trend Line Chart** — Pure CSS trend visualization with historical and predicted data
- **Prediction Cards** — Forecasts with confidence intervals and risk assessments
- **Accuracy Metrics** — Model performance tracking (MAE, RMSE, R²)
- **Time Series Analysis** — Multi-period forecasting with seasonal decomposition

## Tech Stack

- Vanilla HTML/CSS/JavaScript
- No external dependencies
- Data science theme with professional visualization

## Getting Started

Open `index.html` in any modern browser to explore predictions and forecasts.
